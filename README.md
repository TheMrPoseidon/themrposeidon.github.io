# themrposeiodon.github.io

## Prerequisites

- [git](https://git-scm.com/) installed
- [python](https://www.python.org/) installed
- [uv](https://github.com/astral-sh/uv) installed

## Setup

1. Clone repository
   ```bash
   git clone git@github.com:TheMrPoseidon/themrposeidon.github.io.git
   cd themrposeidon.github.io.git
   ```
2. Install dependencies
   ```bash
   uv sync
   ```

## Development

```bash
uv run zensical serve
```

After that the documentation is available here: [http://localhost:8000](http://localhost:8000)
